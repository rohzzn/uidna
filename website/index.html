09 Notes


Notes, assembly and links


General notes


    

  1. Every non-GET request is blocked while exploring, beacons included.
    2. 

  2. Crawls stay on one origin, honor robots.txt and are rate-limited.
    3. 

  3. Secrets are redacted before anything is stored.
    4. 

  4. Never gets around logins, CAPTCHAs or access controls. Never stores credentials.
    5. 



Exclusions


    

  • iframe content and shadow DOM are not entered.
    • 

  • Inline SVG markup becomes a placeholder.
    • 

  • Crawls follow same-origin links, up to 50 pages.
    • 

  • Server responses to form submissions are never observed.
    • 

  • Container queries, clamp() and vw values are not breakpoints.
    • 

  • The generated project is a baseline your agent repairs.
    •
